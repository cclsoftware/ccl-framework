# ccl-extras

CCL utilities for Python development.

# Installation

Install from GitHub directly, either use HTTPS or SSH:

```
pip install git+https://github.com/cclsoftware/ccl-framework-development.git#subdirectory=ccl/extras/python
pip install git+ssh://git@github.com/cclsoftware/ccl-framework-development.git#subdirectory=ccl/extras/python
```
