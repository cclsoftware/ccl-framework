Changelog
#########


Version 1.1.0
=============

Release date: 2025-06-13.

* Suggested keeping function argument count to 5 or fewer.
* Added guidance to avoid empty 'default' cases in switch statements.
* Clarified macro usage: avoid unnecessary semicolons.
* Expanded constructor guidelines and added inheritance order rule.
* Updated comment rules: avoid ticket numbers and unrelated code references.
* Added template whitespace rule: no space before opening angle bracket.
