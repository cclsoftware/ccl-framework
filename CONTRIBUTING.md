# Contributing to Crystal Class Library

Contributions to CCL are welcome via pull requests. You need to sign the [CCL Contributor License Agreement](https://cla-assistant.io/cclsoftware/ccl-framework) (CLA) before contributing. The CLA assistant will automatically check pull requests, and you only need to sign once.

Make sure to follow the [CCL Coding Conventions](https://cclsoftware.github.io/ccl-documentation/codestyle/) and [Code Review Checklist](https://cclsoftware.github.io/ccl-documentation/codereviewguide/checklist.html).

CCL is primarily developed in a private repository, with selected branches mirrored to a public repository. Contributions are reviewed, may be adjusted as needed, merged into the private repository first, and then mirrored back to the public repository.
